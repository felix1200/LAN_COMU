# 公司内网 Web 即时通讯系统 — 需求基线（已确认版）

> 适用：公司内网使用，仅内网访问，外网禁止访问
> 开发模式：扣子 AI 编程生成源码 → Git 拉取 → 内网 Windows 服务器自建运行（Node.js + MySQL + 本地磁盘）
> 部署：脱离扣子公有云独立运行

## 0. 技术栈（已确认）

- 前端：React / Vue
- 后端：Node.js
- 实时通信：WebSocket（断线自动重连）
- 数据库：本地 Windows MySQL
- 密码：bcrypt 哈希存储
- 文件存储：Windows 服务器本地磁盘，MySQL 只存路径 + 原始文件名

## 1. 系统全局规则

1. 仅限公司内网访问，外网禁止访问
2. 数据库：本地 MySQL；密码 bcrypt 加密，不存明文
3. 文件：实体存服务器本地磁盘，MySQL 仅存路径；保留原始文件名；单文件上限 100MB；仅支持下载，不做在线预览
4. 数据保存：聊天文字、文件记录永久保存，不自动删除；前端隐藏会话仅本地生效，数据库保留
5. 登录会话：永久保持自动登录，关闭浏览器无需重新登录；登录失败可配置锁定；密码复杂度不强制

## 2. 用户端页面

### 2.1 注册页
- 输入项：用户名、密码、真实姓名（仅三项）
- 提交后状态为「待审核」，无法登录；管理员审核通过后方可登录，驳回的禁止登录
- 注册页不能注册管理员账号；超级管理员后台手动预置

### 2.2 登录页
- 校验账号状态：待审核/驳回/禁用 → 提示无法登录
- 通过且正常 → 登录成功，建立永久登录会话
- 密码对比 bcrypt 哈希

### 2.3 主聊天页
- 左侧会话列表：所有私聊/群聊会话，显示会话名、未读红点+数量、在线/离线状态；可隐藏会话（仅前端隐藏）
- 聊天窗口（私聊/群聊共用）：文字消息、上传文件（≤100MB）、已读标记、实时推送、断线重连自动加载历史、不支持撤回
- 群组：普通用户可建群（创建者为群主）；群主可改名/邀请/踢人；普通成员仅收发消息和文件
  - **已确认：成员可主动退群；不支持群主转让、不支持解散群**
  - 群人数无上限
- 搜索：① 搜索用户并发起私聊 ② 检索历史聊天文字内容
- 个人资料：上传自定义头像；查看本人信息

### 2.4 已读标记（已确认）
- 私聊：单条消息已读/未读
- 群聊：显示「X/Y 人已读」人数，不提供已读名单

## 3. 管理员后台（独立入口，单独 URL）

- 预置超级管理员账号，无法从注册页注册管理员
- 功能：① 注册申请审核（通过/驳回）② 账号管理（查看全部、禁用、重置密码、删除账号）
- **已确认：删除账号 = 标记禁用，保留历史聊天记录**
- 仅管理员可见后台入口

## 4. 数据表设计

1. 用户表：用户名、bcrypt 密码、真实姓名、头像文件路径、账号状态（待审核/通过/驳回/禁用）、是否管理员
2. 群组表：群 ID、群名称、群主用户 ID、创建时间
3. 群成员表：群 ID、用户 ID、加入时间
4. 消息表：消息 ID、会话类型（私聊/群）、发送人 ID、消息内容（文字/文件）、文件路径、发送时间、已读状态标记
5. 文件表：文件 ID、原始文件名、服务器存储路径、上传用户 ID、上传时间

## 5. 已确认的默认值

| 项目 | 默认值 |
|------|--------|
| 在线状态 | 30 秒无心跳算离线 |
| 登录失败锁定 | 连续 5 次失败锁 30 分钟 |
| 用户名规则 | 3-20 位，字母/数字/下划线，唯一 |
| 密码 | 至少 6 位，不强制复杂度 |
| 超级管理员 | 初始化脚本预置 admin，首次登录强制改密 |
| 管理员后台 | 独立 /admin 路径，仅管理员可访问 |
| 头像 | ≤2MB，jpg/png/webp |
| 文字消息 | ≤2000 字 |
| 用户搜索 | 用户名/真实姓名模糊匹配 |
| 消息搜索 | 全部历史会话检索，分页展示 |

## 6. 页面清单

1. 用户端：注册页、登录页、聊天主页面、个人资料页
2. 管理端：独立管理员后台页面（单独 URL）
