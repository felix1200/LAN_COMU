# 内信 IntraChat —— Windows 本地部署包

企业内网即时通讯系统：用户注册/审核、登录（永久登录、失败锁定、首登强制改密）、单聊/群聊、
实时消息（WebSocket）、文件分片上传/下载、头像、历史消息/用户搜索、管理员后台。
**脱离任何云，纯本地运行**：Node.js + 本地 MySQL + 本地磁盘存文件。

---

## 1. 环境要求（一次性准备）

| 组件 | 要求 |
|---|---|
| Node.js | 20+ LTS（https://nodejs.org） |
| pnpm | 脚本会自动启用，也可手动 `npm i -g pnpm` |
| MySQL | 8 或 MariaDB 10.4+（本地已装即可，**无需手动建库**，首次启动自动建库建表并预置管理员） |

> 检查 Node：PowerShell 执行 `node -v`。

---

## 2. 三步部署

在**项目根目录**打开 PowerShell，执行：

```powershell
# 第 1 步：安装依赖 + 构建 + 启动（首次）
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1
```

首次运行会：
1. 从 `.env.example` 生成 `.env`（若已有则跳过）；
2. 自动为 `JWT_SECRET` 生成随机密钥；
3. `pnpm install` 安装依赖；
4. 构建前端 `dist/` 与后端 `dist-server/server.js`；
5. 启动服务。

> **务必**：打开生成的 `.env`，核对并填写你的 MySQL 连接：
> ```env
> DB_HOST=127.0.0.1
> DB_PORT=3306
> DB_USER=root          # 建议用独立账号 im_app，见第 4 节
> DB_PASSWORD=你的MySQL密码
> DB_NAME=intranet_im
> ADMIN_USERNAME=admin
> ADMIN_INITIAL_PASSWORD=Admin@123456   # 首登会强制改密
> ```
> 改完 `.env` 后重启即可（不必重新构建，密钥/DB 变更无需重编）。

启动成功后看到 `Server running at http://localhost:5000`，浏览器打开：

- 登录/聊天：`http://localhost:5000`
- 管理后台：`http://localhost:5000/admin`
- 初始管理员：`admin / Admin@123456`（**首次登录强制改密**）

---

## 3. 之后怎么启动

重新启动（已安装依赖、已构建过，跳过安装/构建）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -Start
```

想看构建日志/换端口：在 `.env` 里加 `PORT=5000`（改数字）。

---

## 4. 建议：用独立 MySQL 账号（可选但推荐）

打开 MySQL（命令行或图形工具）执行：

```sql
CREATE DATABASE IF NOT EXISTS intranet_im CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'im_app'@'localhost' IDENTIFIED BY '你的强密码';
GRANT ALL PRIVILEGES ON intranet_im.* TO 'im_app'@'localhost';
FLUSH PRIVILEGES;
```

再把 `.env` 里 `DB_USER=im_app`、`DB_PASSWORD=你的强密码`。

---

## 5. 常驻 / 开机自启（部署到服务器时）

**方式 A：NSSM（注册成 Windows 服务，最稳）**

```powershell
# 先安装 NSSM 并加入 PATH（nssm.cc），然后在项目根目录：
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -Service nssm
```

**方式 B：pm2（简单）**

```powershell
npm i -g pm2 pm2-windows-startup
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -Service pm2
```

## 6. 局域网共享（可选）

其他电脑用 `http://本机内网IP:5000` 访问。需在 Windows 防火墙放行 **TCP 5000**：
控制面板 → 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → `5000` → 允许。

## 7. 目录与数据

| 路径 | 说明 |
|---|---|
| `uploads/` | 聊天文件与头像（运行时生成，请备份） |
| `.env` | 本地配置（含数据库密码、JWT 密钥，**不要外传/入库**） |
| `database/schema.sql` | 建表脚本（程序也会自动建，此文件供手动导入/排障） |
| `dist/`、`dist-server/` | 前端/后端构建产物 |

备份 = 备份 `MySQL 库` + `uploads/` 目录 + `.env`。

## 8. 常见问题

- **端口被占用**：改 `.env` 的 `PORT`。
- **连不上 MySQL**：确认服务已启动、`DB_HOST/DB_PORT/账号密码` 正确；程序若连不上会在控制台明确报错。
- **上传中断/大文件失败**：本系统已实现**分片上传**（4MB/片，失败自动重试），本地内网直连一般不会断；单文件上限 100MB（`MAX_UPLOAD_MB`）。
- **忘记 admin 密码**：删掉 MySQL 中该账号或用管理后台「重置密码」，或提供一枚已登录管理员令牌在管理后台重置。
